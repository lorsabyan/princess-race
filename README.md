# Արքայադստեր մրցարշավը 👑🚗

3D բրաուզերային խաղ 5 տարեկանների համար․ արքայադուստրը վարդագույն մեքենայով հավաքում է
ոսկե մետաղադրամներ և շրջանցում խոչընդոտները։

**🎮 Խաղալ՝ https://lorsabyan.github.io/princess-race/**

Կառուցված է **Three.js + Vite + TypeScript**-ով․ ամբողջ գրաֆիկան և ձայները գեներացվում են
կոդով (առանց asset ֆայլերի)։

## Գործարկում

```sh
npm install
npm run dev      # http://localhost:5173
```

## Production build

```sh
npm run build    # արդյունքը՝ dist/ թղթապանակում
npm run preview  # build-ի տեղային ստուգում
```

## Հրապարակում GitHub Pages-ում

Կայքը սպասարկվում է `gh-pages` ճյուղից։ Նոր տարբերակ հրապարակելու համար՝

```sh
npm run deploy
```

## Կառավարում

- **Ստեղնաշար․** ← → (կամ A / D), P/Esc՝ դադար
- **Հպում․** էկրանի ձախ/աջ կեսին հպել, կամ էկրանի ◀ ▶ կոճակները
- 3 սրտիկ, բախումից հետո՝ կարճ անխոցելիություն
- Ռեկորդը, մետաղադրամների բանկը, անունն ու գույնը պահվում են բրաուզերում (localStorage)

## Հնարավորություններ

- **Բոնուսներ․** 💗 սրտիկ (վերականգնում է), 🧲 մագնիս (ձգում է մետաղադրամները), ⭐ վահան (խոչընդոտները պայթում են)
- **Փոփոխվող տեսարաններ․** օր → մայրամուտ → աստղային գիշեր → ձմեռ ձյունով → ծովափ (ամեն 40 մետաղադրամից)
- **Ավտոտնակ․** հավաքած մետաղադրամներով բացվող մեքենայի գույներ
- **Հաղթողի պոդիում** 1-3 աստղով, արքայադստեր անունով
- **Երկնքի կյանք․** թիթեռներ, թռչունների երամ, օդապարիկներ
- **PWA․** iPad/հեռախոսի հոմ-էկրանին ավելացվող, offline աշխատող
- 🐢 Հանգիստ / 🐰 Արագ ռեժիմ, դադարի կոճակ, ավտոմատ դադար ներդիրը թաքցնելիս

## Կոդի կառուցվածք

| Ֆայլ | Պատասխանատվություն |
|---|---|
| `src/game.ts` | Խաղի ցիկլ, վիճակներ, բախումներ, խցիկ, bloom |
| `src/world.ts` | Երկինք, ծիածան, արև, ամպեր, ճանապարհ, ծառեր |
| `src/car.ts` | Վարդագույն մեքենան և արքայադուստրը |
| `src/spawner.ts` | Մետաղադրամների ու խոչընդոտների սփոն (object pooling) |
| `src/particles.ts` | Աստղափայլ պայթյուն մետաղադրամ հավաքելիս |
| `src/audio.ts` | Web Audio սինթեզված ձայներ ու երաժշտություն |
| `src/ui.ts` | HUD, էկրաններ, ստեղնաշար/հպում |
